# IT過去問マーカー v2（CBT準拠版）

ITストラテジスト試験 午後I（新CBT制度では「科目B-1」に相当）の過去問PDFを読み込み、
IPA公式CBT試験アプリの操作画面（公式資料「CBT科目B_論述あり.pdf」に準拠）に近づけた
マーカー・別画面機能で学習できる静的Webアプリです。

> **これは v1（`ipa-kakomon-marker`、ポート8000）とは完全に独立した別フォルダ・別ポート・別ブラウザストレージのバージョンです。**
> v1は一切変更していません。詳しくは [CBT_V2_CHANGES.md](CBT_V2_CHANGES.md) を参照してください。

## v1からの変更点（ハイライト）

- マーカー色を公式CBTと同じ **赤・青・黄の3色** に変更し、ツールバーの並び順も公式準拠
  （通常ポインター → 赤 → 青 → 黄 → 消しゴム → サイズ → クリア）
- マーカーの **太さ（サイズ）をスライダーで変更可能**
- **「問題（別画面）」** を追加。問題文を独立したフローティングパネルで開け、
  ドラッグで移動・端のハンドルでリサイズ・「標準／大」ボタンでサイズ切替ができる
- 別画面のマーカーはメイン画面とは**同期せず独立して保存**（公式仕様どおり）
- ズームを**スライダーでも**操作可能に（＋／－ボタンは維持）

詳細は [CBT_V2_CHANGES.md](CBT_V2_CHANGES.md) を参照してください。

## 収録内容

- ITストラテジスト試験 午後I の**平成21年度（2009年度、制度開始年）〜令和7年度（2025年度）の全16セッション**
  （令和2年度は新型コロナウイルス感染症拡大防止のため試験中止となり、過去問自体が存在しません）
- 各年度の「問題冊子」と「解答例」の両方
- 出典・利用条件の詳細は [SOURCES.md](SOURCES.md) を参照してください（著作権はIPAに帰属します）

## 使い方

1. トップ画面で読みたい年度の「問題を読む」または「解答例を見る」を選びます。
2. 「↖（通常ポインター）」でスクロールして問題文を読みます。
3. 赤・青・黄のいずれかをタップ（クリック）すると、その色のマークモードになります。指やマウスでなぞるとマーカーが引けます。
4. 「⌫（消しゴム）」で、引いたマーカーの上をなぞると部分的に消せます。「クリア」で一括消去（確認あり）。
5. 「サイズ」スライダーでマーカーの太さを変更できます。
6. 下部の「問題（別画面）」で、同じ問題文を別のフローティングパネルに表示できます。ヘッダーをドラッグして移動、右下の角をドラッグしてリサイズ、「標準／大」で定型サイズに切り替えられます。別画面のマーカーはメイン画面とは別に保存されます。
7. マーカーの位置はこの端末のブラウザ内（localStorage）にのみ保存され、外部へは送信されません。

## なぜ「なぞって引く」方式なのか

IPAの問題冊子PDFを調べたところ、実は**ページ全体がスキャン画像として貼り付けられているだけで、テキストは含まれていません**（テキスト選択でのハイライトができない）。
そのため、テキスト選択ではなく公式CBTと同じ「ドラッグしてなぞる」操作を採用しています。

## ローカルでの実行方法

```bash
cd IT_Strategist_CBT_Viewer_v2
python3 -m http.server 8001
```

ブラウザで `http://localhost:8001` を開きます（v1が使っている8000番とは別ポートです。同時に起動しても競合しません）。
インターネット接続がなくても、一度読み込んだ後は動作します（PDF・PDF.js・フォントデータはすべてプロジェクト内に同梱済みです）。

## 使用技術

- HTML / CSS / JavaScript（ESモジュール、外部フレームワーク不使用）
- [PDF.js](https://github.com/mozilla/pdf.js)（Mozilla, Apache-2.0）を `vendor/pdfjs/` へ同梱（CDN不使用）
- Canvas API（マーカー描画）/ Pointer Events API（マーカー・ドラッグ・リサイズ操作）
- localStorage（マーカー位置の保存のみ。画像・PDF本文・個人情報は保存しません）

外部ライブラリの詳細・ライセンスは [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

## 開発者向け：PDF.jsの再取得

```bash

npm run vendor:copy
```

## データの取り扱い

- 過去問PDF本文はアプリに同梱されたファイルをそのまま表示しているだけで、外部通信は行いません。
- マーカーの位置情報のみ、この端末のlocalStorageに保存されます（PDF本文は保存しません）。
- v1と同じ端末で使っても、localStorageのキー名を分離しているため、v1のマーカーとは混ざりません。
- 詳しくは [SOURCES.md](SOURCES.md)（出典・利用条件）を参照してください。
